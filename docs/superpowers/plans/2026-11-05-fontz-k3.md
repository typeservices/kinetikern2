# Fontz Kinetikern3 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for implementation and independent review. Track completion below.

**Goal:** Deliver a retrained, selectable Fontz harness in the local Kinetikern3 Glyphs plugin.
**Architecture:** A standard-library profile module validates engine and punctuation identities. The existing Plan accepts an explicit table, preserving the Google Fonts default. Offline tools adapt the frozen Fontz corpus to the current bridge and punctuation model, then fit and evaluate a separate table.
**Tech Stack:** Python, NumPy, fontTools, HarfBuzz, existing Rust dynamic library and vanilla UI.
